# Campus Food
Campus Food is a campus food ordering website designed to make ordering food from different campus restaurants simple and convenient.

Features
- Browse campus food items
- Search for food
- Filter food by category and type
- Browse food by restaurant
- Add food items to cart
- Increase or decrease item quantities
- Cash on Delivery payment
- UPI payment
- Friendship Group ordering
- Create a group and add individual members
- Select food separately for each group member
- Review the complete group order before placing it
- Order confirmation

Technologies Used

- HTML5
- CSS3
- JavaScript
